  Language Model, LLM）に渡し、回答を取得できます。

# Agent の概要

## **主なメリット**

<figure><img src="../.gitbook/assets/image (122).png" alt=""><figcaption></figcaption></figure>

* **多様性**：さまざまな Agent タイプを提供し、異なる利用ニーズに対応します。簡単な設定で高品質な Agent アプリケーションを構築できます。
* **ガバナンスの実現**：Agent の利用権限を管理でき、生成 AI の活用が企業の規範に準拠することを確保します。
* **正確性**：ナレッジベース内の情報を組み合わせて回答を生成し、ハルシネーション（hallucination）のリスクを低減します。
* **柔軟性**：hybrid な利用シーンをサポートし、開発者は実際のニーズに応じていつでも LLM モデル／サービスを差し替えられます。
