## **主要機能と技術的特長**

* **Knowledge Base**：簡単な3ステップでドキュメントのナレッジベースを構築でき、大規模言語モデルが内蔵する知識の不足や信頼性の低い回答の問題を解決します。さらに、分野の専門家に管理権限を付与し、安全な環境でそれぞれのナレッジベースを維持できるため、重要な知識の漏洩を防ぎます。
* **Agent**：さまざまな利用シーンに応じて Agent を迅速に生成し、権限付与によってユーザーがすぐに活用できるようにします。
* **プロンプトアプリ / テンプレート管理**：よく使うプロンプトを定型化してアプリ化することで、ユーザーは重要な情報を入力するだけで質問応答の精度を高められ、大量のプロンプトを自分で入力する必要がなくなります。
* **AI ワークフロー (AI Workflow)**：柔軟な AI フロー機構により、さまざまな RAG の利用シーンに対応し、外部の統合検索機構とも連携できます。RAG の設計効率を高め、AI Studio の活用可能性をさらに広げます。

> **注意：** 以下のスクリーンショット内の情報は参考用です。実際の会話履歴、Agent、プロンプトテンプレートなどは、お使いの環境の内容を基準としてください。
