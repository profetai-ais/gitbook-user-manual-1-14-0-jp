# API Key

## はじめに

API Key を使うと、ユーザーは専用の API キーを作成し、外部システムが AI Studio のサポートするオープン API を呼び出せるようになります。API Key を利用すれば、外部プログラム、連携サービス、サードパーティツールは、アカウントとパスワードでログインすることなく、キーに紐づくユーザーの権限に従って API を呼び出せます。ここで新しい API Key を作成したり、API ドキュメントを開いて利用可能な API 仕様を確認したりできます。

各 API Key は、そのキーを作成したユーザーに紐づけられ、システムはそのユーザーの権限に基づいてアクセス可能な API の範囲を判定します。

## API Key の設定

API Key ウィンドウを開いた後、生成ボタンをクリックするとキーが一組生成されます。

<figure><img src="../.gitbook/assets/image (336).png" alt=""><figcaption></figcaption></figure>

> 注意： API Key の作成後、完全なキーの内容は一度だけ表示されます。セキュリティ上の理由から、システムは完全なキーを再表示せず、元のキーを復元することもできません。キーを紛失した場合は、元のキーを削除してから再作成してください。\
> 各ユーザーが作成できる API Key は最大1つです。新しい API Key を生成する必要がある場合は、先に元の API Key を削除してから再生成してください。

### API Key の管理

API Key を作成すると、ユーザーは自分が作成したすべてのキーを確認できます。キーのセキュリティを保護するため、リストにはマスクされた形式のキーのみが表示されます。例：

```
gak_abc*******xyz
```

API Key を無効化または削除すると、外部システムはそのキーで API を呼び出せなくなります。キーに有効期限が設定されている場合、システムは期限到来後に自動的にそのキーを失効させます。

> 注意： API Key を、フロントエンドのコード、公開された Git リポジトリ、保護されていないドキュメントなどの公開環境に露出させないでください。API Key が漏洩した疑いがある場合は、ただちにそのキーを無効化または削除し、新しい API Key を再作成してください。

## API ドキュメント

API ドキュメントのブロックで、ユーザーは API ドキュメントを開くことができます。API ドキュメントには利用可能な API 仕様が表示され、Swagger UI を通じて API のパス、パラメータ、テストリクエストを確認できます。

## 利用履歴

利用履歴タブに切り替えると、ユーザーは API Key の利用履歴を確認できます。利用履歴は、外部システムの呼び出し状況を追跡し、異常なリクエストがないか確認するのに役立ちます。また、日付範囲を指定して特定期間内の API 呼び出し履歴を検索することもできます。
