# パーソナライズ

## はじめに

パーソナライズは、Agent がその後のやり取りで重要な情報を「記憶」し「継続して利用」できるようにする機能で、会話の一貫性とタスク処理の効率を高めるためのものです。ユーザーがやり取りの中で好み、背景情報、よく使う設定、プロジェクトの文脈、決まった形式などの情報を提供すると、システムはそれらを再利用可能な記憶として整理し、Agent が以降の会話で自動的に参照できるようにします。これにより、繰り返しの説明や確認のやり取りを減らせます。

例えば、ユーザーがよく使う呼び方、口調のスタイル、出力形式（箇条書き／表／段落）、よく扱う製品やプロジェクト名、フローの好み、よくある意思決定の原則、長期的に一貫性を保つ必要のあるルールなどを、記憶として保持し、適切なタイミングで適用できます。

記憶機能の入口は、右上のアバターにある「パーソナライズ」タブです。

### あなたについて

個人情報を追加すると、Agent はよりパーソナライズした返信を生成できます。

<figure><img src="../.gitbook/assets/image (127).png" alt=""><figcaption></figcaption></figure>

### 記憶

記憶は「記憶の保存」と「記憶の参照」に分かれます。

<figure><img src="../.gitbook/assets/image (128).png" alt=""><figcaption></figcaption></figure>

* **記憶の保存**：オンにすると、Agent が記憶を保存できるようになります。
* **記憶の参照**：オンにすると、Agent が応答時に記憶ライブラリ内の記憶を引用できるようになります。

## 記憶の管理

記憶管理の入口は「管理」ボタンにあり、記憶管理は「個人記憶」と「Agent 記憶」に分かれます。

<figure><img src="../.gitbook/assets/image (129).png" alt=""><figcaption></figcaption></figure>

### 個人記憶

記憶の参照機能がオンのとき、ここに保存された記憶はすべての Agent が呼び出せます。個人記憶は最大50件まで保存できます。

> Note：保存上限を超えると、システムは利用頻度が最も低い記憶項目を自動的に削除します。

<figure><img src="../.gitbook/assets/image (130).png" alt=""><figcaption></figcaption></figure>

### Agent 記憶

記憶の参照機能がオンのとき、Agent は自分の記憶ライブラリ内の記憶を呼び出せます。各 Agent は最大50件の記憶項目を保存できます。

> Note：保存上限を超えると、システムは利用頻度が最も低い記憶項目を自動的に削除します。

<figure><img src="../.gitbook/assets/image (131).png" alt=""><figcaption></figcaption></figure>

1. 記憶機能を使う前に「記憶の保存」がオンになっていることを確認してください。
2. 会話画面で会話する Agent を選択し、記憶させたい内容を入力します。
3. 記憶に成功すると、Agent は「パーソナライズ → 記憶管理」で記憶を確認できることを案内します。
