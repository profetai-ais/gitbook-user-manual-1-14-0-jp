# 監査ログ

## はじめに

監査ログは、システム内の重要なオブジェクトの操作記録を記録し、管理者がプラットフォーム内でのユーザーの追加、編集、削除などの行為を追跡するのを支援します。監査ログを通じて、ユーザーは操作時刻、操作者、オブジェクトの種類、オブジェクト名、変更内容を確認でき、システム管理、問題の追跡、データ監査を行いやすくなります。

## 欄の説明

| 欄   | 説明                                         |
| ---- | ------------------------------------------ |
| 操作タイプ | 操作されたオブジェクトの種類を表示します。例：Agent、データセット、スキル、ワークフローテンプレート、プロンプトテンプレートなど。 |
| 操作名 | 操作されたオブジェクトの名前を表示します。名前をクリックすると、その操作の詳細な変更内容を確認できます。             |
| アクション   | 操作の種類を表示します。例：CREATE、UPDATE、DELETE。            |
| 操作者  | その操作を実行したユーザーを表示します。                               |
| 作成日 | その操作記録が作成された時刻を表示します。                             |

## 監査ログ内容の確認

<figure><img src="../.gitbook/assets/image (377).png" alt=""><figcaption></figcaption></figure>

ユーザーは一覧の操作名をクリックして監査ログプレビューウィンドウを開き、その操作の詳細内容を確認できます。

**変更前**と**変更後**のブロックでは、システムがその操作によって生じたデータの差分を表示します。ユーザーはこの内容で、操作前後のオブジェクトの変更状況を確認できます。

操作タイプによって表示される変更内容が異なります。例えば、**追加** 操作は通常、追加後のデータ内容を表示します。**更新** 操作は修正前後の差分を表示します。**削除** 操作は、削除されたオブジェクトの関連情報を追跡するのに使えます。

## 検索とフィルター

<figure><img src="../.gitbook/assets/image (378).png" alt=""><figcaption></figcaption></figure>

ユーザーはページ上部の検索欄に名前を入力し、特定のオブジェクトの操作記録を素早く見つけられます。

また、フィルター機能を使って照会範囲を絞り込めます。例えば、オブジェクトの種類、操作タイプ、操作者、時間範囲で記録を照会できます。フィルター条件は、特定期間や特定ユーザーの操作記録を素早く見つけるのに役立ちます。

## 監査ログのエクスポート

監査記録を保存したりさらに分析したりする必要がある場合、ユーザーは右上の**エクスポート**ボタンをクリックして監査ログエクスポートウィンドウを開けます。

<figure><img src="../.gitbook/assets/image (392).png" alt=""><figcaption></figcaption></figure>

エクスポート前に以下の条件を設定できます：

| 欄           | 説明         |
| ------------ | ---------- |
| 操作タイプ         | エクスポートするオブジェクトの種類を選択します |
| アクション           | エクスポートする操作タイプを選択します |
| 操作名         | 指定のオブジェクト名を入力します   |
| 操作者          | 操作を実行したユーザーを選択します |
| 開始時刻 \~ 終了時刻 | エクスポートする時間範囲を設定します |

条件の設定が完了したら、以下の形式でエクスポートできます：

* **CSV エクスポート**：CSV ファイルとしてエクスポートします。スプレッドシートツールでの確認や整理に適しています。
* **JSON エクスポート**：JSON ファイルとしてエクスポートします。システム連携、データ交換、技術的分析に適しています。

## 注意事項

監査ログは主にシステムの操作記録を追跡するために使います。確認できる記録の範囲はユーザーの権限によって異なります。

特定の記録が照会できない場合は、検索条件、フィルター条件、時間範囲が正しいか確認してください。条件を調整した後、条件に合う監査記録を再度照会またはエクスポートできます。
