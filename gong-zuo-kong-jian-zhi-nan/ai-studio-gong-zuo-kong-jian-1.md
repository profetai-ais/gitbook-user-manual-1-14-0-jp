# 対話スペース

## ページガイド

インターフェースは主に2つの部分で構成されます：

* **会話履歴**：ユーザーは新しい会話を作成したり、過去の会話履歴に素早くアクセスしたりできます。
* **チャットエリア**：Agent と会話を行う場所です。

> 注意： 以下のスクリーンショットは参考用です。実際の会話履歴、Agent、プロンプトテンプレートはお使いの環境によって異なる場合があります。

会話履歴エリアは2つの部分に分かれます：

* **最近の会話** ：作成した会話スレッドはこのエリアに保存され、任意のスレッドをクリックするとチャットエリアで開けます。
* **最近の Agent**：会話したことのある Agent がここに表示されます。

## **チャットでプロンプトテンプレートを使用する**

* プロンプト入力エリアで「/」キーを押すか、「+」の「プロンプトテンプレート」をクリックすると、利用可能なプロンプトテンプレートのリストが表示されます

## **チャットセッションのファイル**

Agent との会話では、2種類のファイルが関わります。「…」内のファイルアイコンをクリックすると**閲覧**でき、権限に応じて**ダウンロード**や**削除**などの操作を実行できます：

### ファイルアイコン

* **参照ファイル**：ユーザーがプロンプトの添付として アップロードしたファイル。
* **作業ファイル**：Agent が応答や出力の中で生成したファイル。

ダウンロードとアクセス権限の説明：

* システムは、ナレッジベース／データセットのダウンロードアクセス制御（Download access control）とユーザーのログイン状態に基づいて、ダウンロードを許可するかどうかを判定します。
* ユーザーが権限を付与されていない、または認証を完了していない場合、システムはダウンロードをブロックしたり、ダウンロード入口を非表示にしたり、権限不足の通知を表示したりすることがあります。
* Agent が応答で生成した「作業ファイル」も、その出所が管理対象データに関わる場合は、同じアクセスルールが適用されます。

## **使用クォータ**

**使用クォータ** エリアでは、ユーザーが **AI Studio ワークスペース** で AI モデルを使用する際の Token とコストの消費状況を明確に把握できます。Token は処理される最小のデータ単位を表し、ユーザーの入力とモデルの出力を含みます。この機能により、ユーザーは使用状況をリアルタイムで追跡・管理できます。

> 注意： 既定では、クォータの使用量は毎日自動的にリセットされます。

## Agent の回答品質へのフィードバック

ユーザーは Agent の1回ごとの回答にフィードバックを提供し、記憶検索の品質や Agent の応答精度を高めることができます。各 Agent の回答の下にフィードバックボタンが表示され、ユーザーは肯定的フィードバックまたは否定的フィードバックを選べます。

### 肯定的フィードバックを提供する

Agent の回答がニーズに合っている場合、ユーザーは回答の下の「高評価」ボタンをクリックして肯定的フィードバックウィンドウを開けます。

<figure><img src="../.gitbook/assets/image (334).png" alt=""><figcaption></figcaption></figure>

肯定的フィードバックウィンドウでは、ユーザーは次のようなフィードバック理由を選択できます：

* タスクをうまく解決してくれた
* 指示に従って回答した
* 回答品質が良い
* 速く効率的
* 自律的に実行した動作が役立った
* その他の理由

ユーザーは「詳細」欄に、回答のどの内容が特に役立ったか、どの部分が期待に合っていたかなど、さらに説明を補足できます。この欄は任意です。

### 否定的フィードバックを提供する

Agent の回答がニーズに合わなかった場合、ユーザーは回答の下の「低評価」ボタンをクリックして否定的フィードバックウィンドウを開けます。

<figure><img src="../.gitbook/assets/image (335).png" alt=""><figcaption></figcaption></figure>

否定的フィードバックウィンドウでは、ユーザーは次のようなフィードバック理由を選択できます：

* 意図を誤解した
* 内容が正しくない
* 回答が不完全
* 指示に従って回答しなかった
* 内容が安全でない、または不適切
* その他の理由

ユーザーは「詳細」欄に、回答の誤っている箇所、不足している情報、Agent にどう改善してほしいかなど、さらに説明を補足できます。この欄は任意です。

### 送信済みフィードバックを確認する

フィードバックを送信すると、対応するフィードバックボタンが選択済み状態で表示されます。ユーザーはそのフィードバックボタンを再度クリックして操作メニューを開けます。

「フィードバックを確認」をクリックすると、選択したフィードバック理由や補足説明を含む、以前送信したフィードバック内容を確認できます。

### フィードバックを取り消す

送信済みフィードバックを取り消したい場合、ユーザーは選択済みのフィードバックボタンをクリックし、操作メニューで「フィードバックを削除」を選択できます。

削除後、その回答はフィードバック未提供の状態に戻り、ユーザーは肯定的または否定的フィードバックを選び直せます。

> 注意： 各 Agent の回答にはフィードバックを1回提供できます。フィードバックを送信済みの場合、ユーザーはそのフィードバックを確認または削除し、新しいフィードバック内容を再送信できます。フィードバック内容は今後の Agent の回答品質の改善に使用されるため、補足説明には回答が期待に合った／合わなかった理由を明確に記述することをお勧めします。

## Canvas

Canvas 機能は、AI が生成した内容を右側の作業エリアに表示し、後で確認・編集・整理しやすくする機能です。ユーザーが AI と会話して比較的長文または複雑な内容を生成したとき、Canvas を使ってドキュメント、表、図表、コード、その他の視覚化された内容などを、より見やすいレイアウトで表示できます。

Canvas は、ドキュメントの作成、レポートの整理、データの分析、図表の確認、会話の過程で同じ内容を継続的に修正する場合など、内容を長時間確認・調整する必要がある場面に適しています。ユーザーは左側で AI と議論し、右側で Canvas の内容を確認・維持できるため、チャットメッセージの中で内容を繰り返し探す手間を減らせます。

### Canvas の呼び出し

<figure><img src="../.gitbook/assets/image (106).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (108).png" alt=""><figcaption></figcaption></figure>

1. 左下の「+」をクリックし、Canvas を選択すると、機能が入力欄に表示されます。
2. チャットウィンドウで要件を入力し、AI にドキュメント、表、図表、その他の内容を生成するよう依頼します。
3. システムが Canvas で表示できる内容を生成すると、画面に Canvas カードが表示されます。
4. Canvas カードをクリックすると、システムは内容を右側の Canvas 作業エリアに開き、ユーザーは Canvas で完全な内容を確認できます。
5. 内容を調整したい場合は、引き続きチャットウィンドウで AI に修正を依頼するか、システムのサポート状況に応じて Canvas の内容を直接編集できます。修正後の内容は Canvas に表示され、ユーザーは継続的に確認・整理できます。

> 注意： Canvas は、長め・複雑、または繰り返し確認・修正が必要な内容に適しています。短いテキスト返信の場合、システムは Canvas を開かず、チャットウィンドウに直接表示することがあります。\
> 内容の種類によってサポートされる操作方法が異なる場合があります。例えばドキュメント、表、図表、コードでは表示や編集の方法が異なることがあります。Canvas の内容が AI によって生成されたものである場合、採用する前に内容が正しいか再確認し、必要に応じて AI にさらに修正や補足を依頼することをお勧めします。



## 音声テキスト変換

音声入力機能は、ユーザーが音声でテキスト内容を入力するのを支援します。ユーザーはマイクをオンにして話し始めるだけで、システムが音声内容をテキストに変換し、手動入力の時間を減らして、データ入力やテキスト入力の効率を高めます。

<figure><img src="../.gitbook/assets/image (142).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (143).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (144).png" alt=""><figcaption></figcaption></figure>

1. Agent の会話ページに入り、テキスト入力欄の横のマイクアイコンをクリックします。
2. システムがマイクの権限を要求した場合は、システムによるマイクの使用を許可してください。
3. 入力したい内容をはっきりと話し始めます。
4. 音声の録音が完了したら、「確認」ボタンをクリックします。
5. 変換が完了すると、テキスト内容が入力欄に表示されます。テキスト内容が正しいか確認し、誤字や意味の不完全な箇所があれば手動で修正してから送信してください。

> 注意： 音声認識の精度を高めるため、静かな環境でこの機能を使用し、はっきりと安定した速度で話すことをお勧めします。周囲の騒音が多い、話す速度が速すぎる、発音が不明瞭な場合は、システムの認識結果に影響することがあります。\
> 音声変換には処理時間がかかります。確認ボタンをクリックした後、システムが変換を完了するまでお待ちください。変換されたテキストには誤字、抜け字、句読点の不完全さが生じることがあるため、送信前に必ず内容を再確認してください。
