## **Agent を探してお気に入りに追加する**

<figure><img src="../.gitbook/assets/image (394).png" alt=""><figcaption></figcaption></figure>

1. ページ左側のメニューで「ワークスペース」をクリックします
2. 使いたい Agent にマウスを合わせるか、検索欄にキーワードを入力して Agent を検索します
3. Agent を選択し、カード上のボタンをクリックしてお気に入りに追加します
4. ページ上部の「お気に入り」ボタンをクリックして個人エリアに切り替え、追加した Agent があるか確認します

## **お気に入りの Agent を確認する**&#x20;

ページ上部の「お気に入り」ボタンをクリックすると個人エリアに切り替わり、自分がお気に入りに追加した Agent やアプリテンプレートを確認できます。Agent／アプリテンプレートのカード右上のメニューボタンをクリックし、ハートボタンを再度クリックすると、選択した Agent／アプリテンプレートをお気に入りから削除できます。
