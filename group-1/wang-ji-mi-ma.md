# パスワードを忘れた場合

## Mail Server が設定されている場合のパスワードリセット <a href="#yi-she-ding-mail-server-shi-zhong-she-mi-ma" id="yi-she-ding-mail-server-shi-zhong-she-mi-ma"></a>

システムに Mail Server が設定されている場合、ユーザーはパスワードリセットメールを通じて自分でパスワードを再設定できます。​

<figure><img src="../.gitbook/assets/image (288).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (289).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (290).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (291).png" alt=""><figcaption></figcaption></figure>



1. ログインページで **Forgot Password?** をクリックします。
2. アカウント情報を入力します。
3. **Retrieve Password** をクリックします。
4. システムがそのアカウントに紐づくメールアドレスにパスワードリセットメールを送信します。メールを開いた後、メール内のパスワードリセットボタンをクリックします。
5. システムがパスワードリセットページに遷移するので、新しいパスワードを入力して確認します。
6. パスワードの更新が完了したら、ログインページに戻り、新しいパスワードで再度ログインしてください。

> 注意： 入力したアカウント情報が登録済みのアカウントと一致しているか確認してください。パスワードリセットメールが届かない場合は、まず迷惑メールやプロモーションメールのフォルダーを確認するか、管理者に連絡してサポートを受けてください。

​

## Mail Server が設定されていない場合のパスワードリセット <a href="#wei-she-ding-mail-server-shi-zhong-she-mi-ma" id="wei-she-ding-mail-server-shi-zhong-she-mi-ma"></a>

システムに Mail Server が設定されていない場合、システムはパスワードリセットメールを送信できません。ユーザーは管理者に連絡し、パスワードのリセットを依頼する必要があります。

<figure><img src="../.gitbook/assets/image (288).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (292).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (293).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (294).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (295).png" alt=""><figcaption></figcaption></figure>



1. ログインページで **Forgot Password?** をクリックします。
2. システムが、パスワードのリセットには管理者への連絡が必要であることを知らせる通知ウィンドウを表示します。
3. 自分で管理者に連絡し、パスワードをリセットする必要があるアカウント情報を提供してください。管理者が仮パスワードをユーザーに提供します。
4. ログインページに戻り、アカウントと仮パスワードを入力します。
5. 仮パスワードでログインすると、システムがパスワード再設定ページに遷移するので、新しいパスワードを入力して確認します。
6. パスワードの更新が完了したら、以降は新しいパスワードでシステムにログインしてください。

> 注意： セキュリティ上の理由から、仮パスワードでログインした後はただちにパスワードの再設定を完了してください。仮パスワードや新しいパスワードを他人に教えないでください。
